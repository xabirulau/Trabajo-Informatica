# Trabajo Informática
Creación de la página web para mostrar cinco simuladores creados utilizando LLM.

El fichero plantilla es la plantilla de diseño html/css que he utilizado para la página web (obtenida a partir de claude).

El fichero index.html es el fichero prinicipal, el que hay que ejecutar. Tiene embebidos los html de cada una de las simulaciones, las cuales están como ficheros independientes nombrados sim*.html. Cada motor de simulación se puede ejecutar también por su cuenta.
